## 💼 LinkedIn (English)

```text
I built a fully local AI video generator — here's how it works.

I wanted to create short cinematic videos from written content without paying per-render or sending my scripts to a cloud service.

So I built one that runs entirely on my machine.

The pipeline:
1. Paste a prompt or essay into the UI
2. A local LLM (Qwen via MLX/Ollama) structures it into cinematic scenes — short, punchy on-screen text with full narration underneath
3. TTS voices each scene (Microsoft Edge TTS or Kokoro running offline)
4. Remotion renders it all into an MP4

What's included out of the box:
• 12 background styles (aurora, nebula, matrix rain, RPG visual novel…)
• 8 text reveal animations (karaoke, glitch, typewriter, blur-in…)
• 7 animated SVG characters with lip-sync + expression control
• Animated sprite characters (pixel art, anime VTuber)
• Ambient background audio tracks
• Cartoon voice presets via pitch/tempo shifting

The interesting part: the renderer never needs the LLM. You can write scenes manually in the editor and render without any AI involved. The LLM is just a drafting shortcut.

Open-sourced it this week for anyone building in the same space.

🔗 github.com/fazleyrabby/remotion-video-generator

#OpenSource #AI #VideoGeneration #Remotion #BuildInPublic #MachineLearning #SideProject
```
